SCB behind NGINX

Each request below runs examples/cgi/handler.scb with scb run, through fcgiwrap. The handler reads the request from \Env\get() and \Io\readAll() and writes headers and body with echo.

Other cases

  • /scb?created — the script echoes Status: 201 Created
  • /scb?fail — throws after the headers: 200 with a truncated body, trace in docker compose logs
  • /scb?fail-early — throws before any output: NGINX answers 502
  • /scb?exit — exit(3) after the body: CGI has no channel for the exit code, so the client gets 200

Response

Status codes and headers: open the browser's network tab, or curl -i 'http://localhost:8080/scb?created'.
